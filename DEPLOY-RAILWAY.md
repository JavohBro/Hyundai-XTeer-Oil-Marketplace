# Развёртывание на Railway

Самый быстрый способ: без сервера, без SSH, HTTPS-домен сразу.
Время: ~20 минут.

> **Про «бесплатно»:** Railway закрыл бесплатный тариф в 2023 году. Сейчас новым
> аккаунтам даётся одноразовый кредит $5 (Trial), дальше — Hobby за $5/мес.
> Для этого приложения расход примерно **$3–5 в месяц**, то есть кредита хватает
> примерно на месяц. Проверьте текущий баланс: **Dashboard → Usage**.
>
> Если нужен именно бесплатный вариант навсегда — смотрите [DEPLOY.md](DEPLOY.md)
> (Oracle Cloud Always Free).

---

## Критично: том для данных

База SQLite и фото товаров лежат в файлах. Файловая система Railway
**стирается при каждом деплое**. Без тома вы потеряете все заказы и картинки
при первом же обновлении кода.

Том настраивается на шаге 3 — не пропускайте его.

---

## Шаг 1. Загрузить код

Railway разворачивает из GitHub. Если репозитория ещё нет:

```bash
git init
git add .
git commit -m "Hyundai Xteer Oil shop"
```

> `.gitignore` уже настроен: `.env`, база и загруженные фото в репозиторий
> **не попадут**. Токен бота останется только у вас.

Создайте пустой репозиторий на GitHub (приватный) и выполните:

```bash
git remote add origin https://github.com/ВАШ_ЛОГИН/oilbot.git
git branch -M main
git push -u origin main
```

---

## Шаг 2. Создать проект

1. [railway.app](https://railway.app) → войдите через GitHub
2. **New Project** → **Deploy from GitHub repo** → выберите `oilbot`
3. Railway начнёт сборку. Первая попытка упадёт — переменных ещё нет, это нормально.

---

## Шаг 3. Том для данных

1. В проекте нажмите на сервис → вкладка **Variables** → рядом **+ New** → **Volume**
2. **Mount path**: `/data`
3. Размер: 1 GB достаточно (это тысячи фото после сжатия)

---

## Шаг 4. Переменные

**Variables** → **Raw Editor** → вставьте:

```ini
BOT_TOKEN=8925813658:AAH1iSasWKIe9_OCUUT0bmWF1ET_9jFK0zI
BOT_USERNAME=hyundaixteeroilbot
ADMIN_IDS=6049615368,795023201
NODE_ENV=production
WEB_AT_ROOT=1
DATA_DIR=/data
NIXPACKS_NODE_VERSION=20
```

`WEBAPP_URL` добавим на следующем шаге, когда появится домен.

> `PORT` задавать не нужно — Railway передаёт его сам.
>
> `DATA_DIR=/data` обязателен: он кладёт базу и фото на том из шага 3.

---

## Шаг 5. Домен

1. Вкладка **Settings** → раздел **Networking** → **Generate Domain**
2. Получите адрес вида `oilbot-production-a1b2.up.railway.app`
3. Вернитесь в **Variables** и добавьте (без слеша в конце):

```ini
WEBAPP_URL=https://oilbot-production-a1b2.up.railway.app
```

Сервис перезапустится автоматически.

---

## Шаг 6. Проверка

Откройте в браузере:

```
https://ваш-адрес.up.railway.app/healthz
```

Ожидается `{"ok":true,"uptime":...}`.

Затем:
- `https://ваш-адрес.up.railway.app/` — сайт
- `https://ваш-адрес.up.railway.app/app` — Mini App

Логи: вкладка **Deployments** → последний деплой → **View Logs**.
Там должно быть `Admins (2): ...` и `Website: ...`.

---

## Шаг 7. Переключить Telegram

Mini App теперь на `/app`, поэтому BotFather нужно обновить.

1. [@BotFather](https://t.me/BotFather) → `/mybots` → ваш бот
2. **Bot Settings → Menu Button** → вставьте:
   `https://ваш-адрес.up.railway.app/app`
3. `/setdomain` → выберите бота → отправьте **только домен**, без `https://`:
   `ваш-адрес.up.railway.app`

Откройте бота, `/start` → «Открыть магазин».

---

## Шаг 8. Перенести текущие данные

На Railway база пустая. Чтобы перенести товары и заказы с ноутбука,
установите Railway CLI:

```bash
npm i -g @railway/cli
railway login
railway link
```

**Остановите локальный сервер**, затем скопируйте файлы на том:

```bash
railway run --service oilbot bash -c "echo ok"
```

Проще всего — через `railway ssh` (если доступен на вашем тарифе):

```bash
railway ssh
```

и внутри проверить `/data`. Для загрузки базы используйте **Volume → Browse**
в веб-интерфейсе Railway: загрузите `oil_bot.db` в `/data`, а фото — в
`/data/uploads`.

> Если товаров немного, быстрее просто добавить их заново через админку —
> фото при этом автоматически сожмутся в WebP.

---

## Резервные копии

Railway не делает бэкапы вашего тома автоматически. Раз в месяц скачивайте
базу через **Volume → Browse → Download** (`oil_bot.db` и папку `uploads`).

Это важнее, чем кажется: в базе вся история заказов и контакты клиентов.

---

## Обновление кода

```bash
git add .
git commit -m "описание изменений"
git push
```

Railway пересоберёт и перезапустит сервис сам. Том с данными не трогается.

---

## Важно: только один экземпляр

В `railway.json` стоит `numReplicas: 1`. **Не увеличивайте.**
Два процесса с одним токеном бота конфликтуют — в логах появится
`409 Conflict`, и сообщения начнут теряться.

По той же причине выключайте локальный сервер на ноутбуке, когда работает Railway.

---

## Если что-то не работает

| Симптом | Причина / проверка |
|---|---|
| Данные пропали после деплоя | Не задан `DATA_DIR=/data` или не создан том (шаги 3–4) |
| `409 Conflict` в логах | Запущено два экземпляра — выключите локальный сервер |
| Сборка падает на `better-sqlite3` | Задайте `NIXPACKS_NODE_VERSION=20` |
| Mini App пустой | В BotFather URL должен оканчиваться на `/app` |
| Кнопка «Войти» не работает | `/setdomain` в BotFather, домен **без** `https://` |
| Сервис остановился | Закончился кредит — **Usage** в дашборде |
| Фото не открываются | Проверьте, что том смонтирован в `/data`, а не в другой путь |
